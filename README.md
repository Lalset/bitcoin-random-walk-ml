# bitcoin-random-walk-ml
## Atividade de aprendizagem de máquina do mestrado envolvendo Random Walk

# Análise do comportamento de Random Walk e previsão de retornos do Bitcoin utilizando aprendizado de máquina

A atividade investiga o comportamento estatístico dos retornos logarítmicos do Bitcoin e avalia a capacidade de previsão de retornos futuros utilizando técnicas de aprendizado de máquina.

## Objetivos

- Investigar características compatíveis com Random Walk;
- Analisar autocorrelação e expoente de Hurst;
- Modelar retornos futuros utilizando Random Forest Regressor;
- Avaliar desempenho utilizando MAE e RMSE.
